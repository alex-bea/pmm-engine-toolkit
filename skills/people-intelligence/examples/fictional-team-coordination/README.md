# Fictional Team Coordination Scenario

This directory is a complete, independently invented demonstration of the skill. Harborlight Operations, its people, sources, dates, decisions, and URLs are fictional. The scenario does not describe a real company, person, customer, or communication record.

Read in this order:

1. [source-map.yaml](source-map.yaml) shows an optional approved-notes source.
2. [evidence-corpus.md](evidence-corpus.md) contains the fictional dated observations and context selection.
3. [prior-brief.md](prior-brief.md) provides the delta baseline.
4. [reference-brief.md](reference-brief.md) provides relational context.
5. [stakeholder-brief.md](stakeholder-brief.md) renders the complete output and writing-preparation prompt.

Every material statement in the completed brief cites a fictional source ID and date from this scenario.
