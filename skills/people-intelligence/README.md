# People Intelligence

Create a consented, evidence-backed professional stakeholder brief for meeting preparation or collaboration planning. This package is self-contained: it does not retrieve data, store adopter records, or connect to external systems.

## Start here

1. Read [the workflow](references/RUN-workflow.md) and [evidence and privacy guidance](references/REF-evidence-privacy.md).
2. Gather only evidence you are allowed to use. The optional [evidence-corpus template](assets/evidence-corpus-template.md) provides a consistent intake shape.
3. Use the [brief template](assets/output-template.md) and [writing-prompt template](assets/writing-prompt-template.md). If recurring approved sources are useful, copy and populate the blank [source-map template](assets/source-map-template.yaml) outside this installed package.
4. Review the complete [fictional scenario](examples/fictional-team-coordination/README.md) for a source-to-output example.

## Boundaries

The skill supports professional collaboration context only. Do not use it to assess sensitive attributes, private life, health, protected characteristics, employment suitability, or personality. Do not infer a recurring preference or pattern from a single observation. Treat optional external systems as adopter-owned adapters and do not search or change them unless the user has expressly authorized that action.

The result is a draft for the stated audience. The adopter owns consent, source authority, access control, retention, correction, deletion, and any local output destination. Return the draft in conversation unless the user explicitly asks to save it to a named location.
