# Daily brief workflow

1. Read configured local sources and record unavailable sources without failing the run.
2. Normalize items into title, source, due date, status, impact, effort, and hold reason.
3. Remove duplicates and items already completed or explicitly dismissed.
4. Place policy-sensitive or unsupported work in `Hold`; do not bury it.
5. Rank remaining work by urgency, impact, dependency leverage, and effort.
6. Select no more than three priorities and render the brief.
