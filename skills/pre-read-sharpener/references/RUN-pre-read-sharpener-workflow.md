# Pre-Read Sharpener Workflow

1. Identify the single decision the reader must make.
2. Remove background that does not affect that decision.
3. State options and their material tradeoffs symmetrically.
4. Give one recommendation and the evidence supporting it.
5. End with the specific decision request and unresolved questions.

Use this skeleton:

```markdown
# [Decision]

## Decision requested
## Context
## Options and tradeoffs
## Recommendation
## Risks and open questions
```

Do not fabricate metrics, timelines, customer examples, or consensus.
