# PMM Habits Workflow

1. Ask for the habits list and a bounded evidence set if either is missing.
2. Match evidence to habits only when the connection is explicit.
3. Use this output format:

| Habit | Evidence | Situation | Next action |
| --- | --- | --- | --- |

4. If no evidence relates to a habit, write `No evidence supplied` rather than guessing.

The goal is a short, actionable reflection—not performance scoring or surveillance.
