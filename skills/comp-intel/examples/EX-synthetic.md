# Offline synthetic walkthrough

This example is fictional and uses reserved example domains. It exercises the same source,
evidence, review, synthesis, change-set, and apply contracts required for live adopters.

1. Initialize an explicit empty data root and run doctor for `synthetic-devtools`.
2. Collect from `2026-08-18` through the exclusive end date `2026-08-26` with a fixed
   observation timestamp when reproducing tests.
3. Review the official fictional release, corroborating documentation, exact duplicate,
   downgraded search snippet, conflicting pricing records, missing publication date,
   out-of-window record, private local note, and instruction-like untrusted text.
4. Install an evidence approval created outside the run by the configured fictional
   reviewer. A conversational “approved” is insufficient.
5. Create a synthesis package using the generated run ID, evidence digest, evidence IDs,
   and current registry digest. A useful package can propose the dashboard capability and a
   battlecard-gap event while preserving the pricing conflict and local-note limitation.
6. Submit it, review the rendered draft and proposed change set, install a separate apply
   approval, and apply.
7. Confirm the canonical registry retains claim/evidence provenance and the report remains a
   local draft for any external-publication purpose.

Before live use, replace every organization-owned item listed in `mapping.json`. Do not edit
the controller or `SKILL.md` to add internal names, channels, systems, intelligence, people,
reviewers, or destinations.
