## How to use this file

For each verified competitor claim:

- **STRONG:** a specific reviewed response exists below.
- **WEAK:** the response is draft, generic, stale, or weakly supported.
- **MISSING:** no useful response exists; propose a battlecard gap.
- **CONFLICTING:** approved internal positions or evidence disagree; route to the owner.

Never overwrite a reviewed response with an unreviewed draft.
