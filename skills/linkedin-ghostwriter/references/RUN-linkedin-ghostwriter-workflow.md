# LinkedIn Ghostwriter Workflow

1. Confirm consent to write in the named person's voice.
2. Load the voice profile and source material supplied for this request.
3. Extract the post's single idea, evidence, and intended reader response.
4. Draft a concise post in the profile's documented style.
5. Check every material claim against the provided source and return the draft for review.

Do not infer a voice profile from public posts, impersonate someone without consent, or
publish a post.
