# Product Page Copywriter Workflow

1. Confirm the product, audience, desired action, and approved evidence.
2. Identify one primary value proposition and up to three supporting pillars.
3. Draft the page using this sequence: hero, proof, problem, pillars, use cases,
   objections, CTA.
4. Check each factual statement against the source material and each tonal choice against
   the supplied style guide.
5. Return the draft plus a short list of `[Missing]` or `[Needs approval]` items.

Never state a performance result, security claim, customer endorsement, comparative claim,
or availability date unless it is explicitly approved in the supplied material.
