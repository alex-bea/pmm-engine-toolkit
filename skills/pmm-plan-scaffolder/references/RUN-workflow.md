# Plan scaffolding workflow

1. Confirm the source idea, decision owner, and plan goal.
2. Classify the artifact as execution plan, strategy reference, or reference-only.
3. Run PM Prioritizer for build-driving work unless explicitly bypassed.
4. Draft the plan with objective, non-goals, evidence, milestones, validation, risks,
   ownership, dependencies, and tracker mapping.
5. Propose one epic and one to three starter tasks. Put deferred slices in `icebox`.
6. Obtain approval before writing the plan or tracker records.
7. Write, validate links and IDs, and summarize what changed.
