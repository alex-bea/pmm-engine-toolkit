# Meeting notes scaffolding workflow

1. Gather meeting name, purpose, cadence, participants or roles, approved source, output
   path, retention expectation, and desired decision/action fields.
2. Copy the config and output templates into the user's local workspace.
3. Add a review-first prompt that extracts only decisions, actions, risks, and open questions.
4. Represent recording, transcription, calendar, or document retrieval as optional adapters.
5. Test with synthetic notes and inspect the local output.
6. Obtain separate approval before scheduling automation or accessing an external source.
