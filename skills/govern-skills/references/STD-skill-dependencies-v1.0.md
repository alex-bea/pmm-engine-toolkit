# Skill Dependency Closure Standard

A public skill package is complete when:

1. `SKILL.md` has exactly `name` and `description` in YAML frontmatter.
2. `agents/openai.yaml` contains quoted display metadata and a prompt naming the skill.
3. Every local path named by `SKILL.md` exists inside the installed package.
4. The package contains the workflows, reusable assets, and synthetic examples required by
   its stated behavior.
5. Deterministic or fragile behavior is implemented in `scripts/` and covered by tests.
6. Required standards are bundled inside the package or installed by its initializer.
7. Optional services are adapters; no private configuration is committed.
8. Missing optional integrations degrade safely and never cause an undeclared fallback.
9. Placeholder files, private examples, local absolute paths, generated bytecode, and
   secrets are absent.
10. Direct GitHub Skill Installer installation does not depend on files outside the selected
    skill directory.
11. Harness-specific adapters are thin and use one shared policy implementation.
12. External approval and publisher implementations are explicit optional adapters; their
    absence denies only actions that require them and never triggers an undeclared fallback.
13. Direct installation without a plugin hook remains usable for audit and planning but
    reports the runtime guard as inactive.
14. Credentials, enabled external-adapter configuration, mutable run state, and protected
    audit records remain adopter-owned and outside the installed package.

Plugin mirrors of canonical repository standards must be checked for byte-for-byte parity
in CI so the installable copy cannot drift from its source.

Run `python3 scripts/governance/validate_skill_pack.py` before releasing this toolkit.
