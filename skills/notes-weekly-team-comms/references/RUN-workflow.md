# Weekly communications workflow

1. Accept structured notes with optional `Shipped`, `In progress`, `Risks`, `Asks`, and
   `Next` headings.
2. Extract claims and preserve source wording where precision matters.
3. Deduplicate by outcome; do not merge separate workstreams just because wording overlaps.
4. Produce a manager wrap, team update, and action list.
5. Flag missing owners or dates rather than assigning them.
6. Review the generated text before saving or sharing.
