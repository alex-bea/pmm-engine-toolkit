# Accepted plan import workflow

1. Confirm the plan content, acceptance statement, approver label, acceptance date, and
   original source. Do not treat mere presence as acceptance.
2. Validate the plan has an objective, owner or `[Missing]`, scope, and acceptance criteria.
3. Create a ledger proposal with a stable content hash; do not duplicate an existing hash.
4. Propose tracker fit: existing epic, new epic, or reference-only, plus starter tasks.
5. Obtain approval for the proposal.
6. Write the acceptance record locally.
7. Obtain a separate approval before writing tracker state.
