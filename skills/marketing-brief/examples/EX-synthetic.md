# Fictional Marketing Brief Example

This example is entirely fictional and demonstrates the expected source-to-brief depth. It
is not evidence for a real product, company, customer, or market.

1. Read the fictional [`source packet`](fictional-report-filters/source-packet.md).
2. Compare it with the canonical [`output template`](../assets/output-template.md).
3. Review the completed [`marketing brief`](fictional-report-filters/marketing-brief.md).

The completed brief uses only facts contained in the source packet, fills all seven sections,
and contains no unfinished placeholders. In real work, unsupported required fields must use
the package's documented missing-data marker rather than content from this example.
