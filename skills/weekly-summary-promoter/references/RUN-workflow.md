# Weekly summary promotion workflow

1. Discover candidate summaries for the requested period.
2. Require explicit `approved` status or direct user approval for each candidate.
3. Verify period, source path, owner, and that material claims retain provenance.
4. Deduplicate overlapping summaries without erasing meaningful disagreement.
5. Render a proposed durable artifact and show its destination.
6. On approval, write locally without overwriting a conflicting file; validate links.
7. Treat any external publication as a separate approval gate.
