# Instinct review workflow

1. Read candidate lesson records from an explicitly supplied local path.
2. Reject candidates without source references, dates, or observable evidence.
3. Cluster only genuinely repeated lessons; preserve counterexamples.
4. Score usefulness, repeatability, specificity, evidence strength, and conflict risk.
5. Choose the narrowest destination: existing skill, shared standard, local preference,
   or no promotion.
6. Draft the exact proposed rule and cite supporting candidates.
7. Promote only after explicit approval and rerun relevant validation.
