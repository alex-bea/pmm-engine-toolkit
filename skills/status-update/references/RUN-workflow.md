# Status update workflow

1. Resolve the reporting window and source list from the local config.
2. Read available sources and record gaps.
3. Normalize each item to date, source, workstream, state, outcome, and evidence label.
4. Deduplicate repeated mentions of the same outcome.
5. Separate accomplished, active, blocked, and next-priority items.
6. Render a concise update and retain source labels for material claims.
7. Save or send only as authorized.
