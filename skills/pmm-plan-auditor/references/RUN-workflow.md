# Plan audit workflow

1. Discover plan files and tracker records without modifying either surface.
2. Validate required plan metadata and referenced tracker IDs.
3. Classify findings as unmapped plan, missing plan, stale status, broken parent, or
   ambiguous ownership.
4. Cite the exact file and record for every finding.
5. Draft a repair package ordered by risk and effort.
6. Apply repairs only after approval, then rerun the audit.
