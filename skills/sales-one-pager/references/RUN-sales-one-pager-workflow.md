# Sales One-Pager Workflow

1. Confirm the audience, use case, and approved product positioning.
2. Extract only facts supported by the supplied materials.
3. Choose a prospect-specific template when the buyer's stated problem is known;
   otherwise use a product overview.
4. Run the evidence check before delivery.

```markdown
# [Product or Use Case]

## The buyer problem
## What changes
## Why it matters
## Evidence and constraints
## Differentiation
## Next step
```

Evidence check: remove unapproved names, logos, metrics, pricing, legal claims, and
competitive comparisons. Flag any unsupported material statement as `[Needs approval]`.
