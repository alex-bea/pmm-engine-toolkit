# AI Skill Governance Standard

## Purpose

Keep skill packages reviewable, safe, and portable.

## Change rules

- Review changes to a skill's behavior, inputs, outputs, permissions, or references.
- Version a skill when its contract changes materially.
- Keep source material traceable. Mark missing facts instead of inventing them.
- Require a human approval gate before publication, external posting, destructive actions,
  or use of regulated or sensitive claims.

## Privacy and IP rules

- Never commit credentials, private URLs, internal identifiers, personal data, customer data,
  or unlicensed third-party content.
- Use generic templates in reusable packages; provide sensitive context only at runtime from
  an authorized user.
- Do not impersonate a person or use a voice profile without consent.

## Validation

Before release, confirm each referenced file exists, examples contain placeholders or
authorized material, and the package can run without an undeclared private dependency.
